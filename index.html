Buscando estágio em Backend Python

01 · Sobre

Aprendizado orientado a projetos

Estou me desenvolvendo na área de Backend Python por meio de projetos práticos, buscando entender não apenas como escrever o código, mas também como organizar as regras de negócio, estruturar uma API e conectá-la ao banco de dados.

Meu principal projeto é o FinTrack, uma API para gerenciamento de carteiras de investimentos. Nele, trabalhei com FastAPI, SQL, PostgreSQL, SQLAlchemy, Docker e modelagem de domínio.

Também realizei o deploy da aplicação no Render, configurando o serviço, as variáveis de ambiente e a conexão com o banco de dados. Atualmente, busco uma oportunidade de estágio para aplicar esse conhecimento em projetos reais e continuar evoluindo com uma equipe.

  • Modelagem de domínio

02 · Projetos

O que venho construindo

Projetos usados para transformar conceitos de backend, dados e matemática em prática.

FinTrack API

Projeto principal · API de carteiras de investimentos

API publicada
  • Python
  • FastAPI
  • PostgreSQL
  • SQLAlchemy
  • Alembic
  • Docker
  • Render

API REST para registrar ativos e consolidar carteiras com renda fixa, ações, fundos imobiliários e criptomoedas. O projeto explora como ativos com regras próprias de rentabilidade podem compartilhar uma estrutura de domínio comum.

Backend e domínio

  • Regras de negócio separadas do framework
  • Validação de dados com Pydantic
  • Persistência com PostgreSQL e SQLAlchemy
  • Migrações de banco com Alembic
  • Autenticação por JWT
  • Uso de Decimal nos cálculos financeiros

Deploy

  • Aplicação containerizada com Docker
  • API publicada no Render
  • PostgreSQL configurado para produção
  • Variáveis de ambiente e conexão da API configuradas
  • Integração com a interface demonstrativa

A interface demonstrativa foi prototipada por geração de prompt em uma ferramenta da Vercel. Meu foco técnico no FinTrack está no backend, na modelagem do domínio e no deploy da API.
